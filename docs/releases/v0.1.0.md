# Sovran 0.1.0 — first public pre-release

**Own your intelligence.** Sovran is an open-source AI coding agent for VS Code that works with the models you
control: on your machine, on your own server, or behind your company's gateway. There is no Sovran backend, no account
and no telemetry. Requests go straight from your editor to the endpoint you choose.

This is the first build you can download and install. It is a **pre-release** (odd minor version): stable enough to use
every day, with real-server compatibility testing still in progress. Feedback from real setups is the most useful
contribution right now.

## Highlights

**Bring your own model**

- Guided setup for Ollama, LM Studio, vLLM and LiteLLM, plus any OpenAI-compatible endpoint or company gateway.
- Context window and output limits read from the server. Keys stay in VS Code Secret Storage.
- Optional `~/.sovran/config.yaml`, kept in sync with Settings both ways.
- Busy servers (429/502/503/504) are retried with backoff before the run fails.

**An agent you stay in charge of**

- **Plan** explores read-only; **Act** edits files and runs commands. Each mode can use its own model.
- **Ask**, **Auto-edit** and **Auto** approval modes. Guardrails for risky commands and protected files still ask in
  every mode.
- Native VS Code diffs, an approval bar above the chat input, **Undo changes** checkpoints, retry, and editing with rewind.

**Tools that fit small context windows**

- Native Git (status, diff, log, branches, and approved staging, commits, push, pull and rebase), workspace
  diagnostics, semantic navigation and `web_fetch` for one public URL at a time.
- Tools are **loaded when needed**. On a 32k window the first request carries about 1,400 tokens of tool definitions
  instead of 4,800.
- A reviewed MCP catalog: Playwright, Chrome DevTools, GitHub, GitLab, Context7, and remote Grafana, Terraform and
  OpenSearch. You can also add your own stdio or HTTP servers. Every tool can be set to **Off**, **Ask** or **Allow**.

**A native VS Code experience**

- Chats in editor tabs that run in parallel, a searchable history that persists across restarts, and chat titles
  written by the model.
- PDF, Office, OpenDocument and ZIP attachments are converted to text on your machine. Images work with vision models.
- `@` file mentions, `/` commands (built-in and your own in `.sovran/commands/`), a context meter and automatic compaction.

## Before you install

- Requires **VS Code 1.95+** and an OpenAI-compatible Chat Completions endpoint. Results depend on your model and server.
- Chats and images are stored **unencrypted** in the workspace storage, and terminal side effects are not checkpointed.
  MCP supports tools only (no OAuth sign-in, resources or prompts).
  See [known limitations](https://github.com/Minells/sovran/blob/v0.1.0/docs/USER_GUIDE.md#known-limitations).
- The VS Code Marketplace listing is not published yet. This release is the official download.
- Report vulnerabilities privately, as described in [SECURITY.md](https://github.com/Minells/sovran/blob/v0.1.0/SECURITY.md).
